# AI 기반 한국어 대화 감정 흐름 분석 시스템

2026-2학기 산학캡스톤디자인 · 팀 안성맞춤 (신제민 · 김예준 · 박기태)

상담 축어록이나 대화 기록을 올리면 **발화 순서에 따른 감정 변화를 곡선으로** 보여주고,
**감정이 크게 바뀐 지점(전환점)** 을 찾아 표시합니다.

A4 15장짜리 상담 기록을 처음부터 읽지 않고도 감정의 흐름을 파악하는 것이 목표입니다.

---

## 폴더 구성

| 폴더 | 내용 | 상태 |
|---|---|---|
| `frontend/` | React 화면 (화면 1~5) | 화면 3·4 구현 완료 |
| `backend/` | FastAPI 서버 — 파싱, 마스킹, 분석, 저장 | 예정 |
| `model/` | 감정 분류 모델 학습 · 평가 | 예정 |
| `scripts/` | 더미 데이터 생성 등 보조 스크립트 | `make_dummy.py` |

각 폴더의 실행 방법은 해당 폴더의 README를 참고하세요.

---

## 빠르게 실행해 보기

현재 프론트엔드만으로도 화면을 확인할 수 있습니다. 더미 데이터가 포함되어 있어 서버 없이 동작합니다.

```bash
cd frontend
npm install
npm run dev     # http://localhost:5173
```

Node.js 20 이상이 필요합니다.

## 화면 구성

| 번호 | 화면 | 설명 |
|---|---|---|
| 1 | 홈 · 업로드 | 파일 선택, 최근 분석 목록 |
| 2 | 분석 진행 | 진행률과 부분 결과 표시 |
| 3 | **결과 대시보드** | 요약 지표 · 감정 색 띠 · 감정 곡선 · 전사본 |
| 4 | 발화 상세 패널 | 감정 분포, 세부 감정, 신뢰도 |
| 5 | 세션 목록 | 저장된 분석 관리, 회기 비교 |

**화면 3이 프로젝트의 핵심**입니다. 곡선·색 띠·전사본이 선택된 발화 번호 하나를 공유해서,
어느 쪽을 클릭해도 나머지가 함께 반응합니다.

## 데이터

학습 데이터는 **AI Hub「감성 대화 말뭉치」** 를 사용합니다.

- 대분류 6종: 불안 · 분노 · 상처 · 슬픔 · 당황 · 기쁨
- 각 대분류마다 소분류 10종 (총 60종)
- 학습용 51,630건 / 검증용 6,641건

**데이터 파일은 저장소에 포함하지 않습니다.** 재배포가 제한되고 용량도 커서,
각자 [AI Hub](https://aihub.or.kr)에서 신청 후 내려받아 주세요.

`frontend/src/data/dummy.json`은 예외로 포함되어 있습니다.
문장은 위 말뭉치에서 추출한 실제 문장이고, 감정 점수는 모델이 준비되기 전까지
화면 개발을 위해 생성한 값입니다. 생성 코드는 `scripts/make_dummy.py`입니다.

## 팀 규칙

- **`frontend/src/types.ts`와 백엔드의 Pydantic 스키마는 서로 거울입니다.**
  한쪽을 바꾸면 반드시 다른 쪽도 바꾸고 팀에 공유해 주세요.
- 비밀번호·API 키는 `.env`에만 두고, 저장소에는 `.env.example`로 키 이름만 공유합니다.
- 업로드된 원본 파일은 서버에 저장하지 않으며, 이름·연락처는 자동으로 마스킹합니다.
- 커밋 메시지는 무엇을 했는지 한 줄로 적습니다. (예: `카카오톡 파서 초안 작성`)
